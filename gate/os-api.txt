# The standard library's identifiers that differ by system, and the decision
# for each. The census,
# `gragas-dev census`, lists them: every exported identifier of an importable
# std package that some first-class port does not declare, declares
# differently or in a per-system file, whose body reaches a per-system
# helper, whose declaration names syscall, or whose doc names a system.
# internal/osapi_test.go holds this list to that census, both ways.
#
# A line is <name> <kind> <rest>, in byte order of the names, each once:
#   <path>.<Name> ban <rule>     a forbidigo row whose message opens with
#                                <rule> refuses it
#   <path>.* ban <rule>          a depguard rule on every file denies the
#                                package with a desc that opens with <rule>
#   <path>.<Name> allow <why>    any package may use it: why it is safe on
#                                every system
#   <name> later #1750 L<n>      row L<n> of the plan of bans is to ban
#                                it and has not yet; the later lines only
#                                shrink against the
#                                merge base with origin/main
#   <path>.<name> allow <why>    a root: a name the reach passes through that
#   <path>..<method> allow <why> no program writes (an unexported name, a
#                                name of an internal package, or a method of
#                                that name of any of the package's types);
#                                allowed only, since no lint row can refuse
#                                what no program writes, and a later there
#                                could never turn into a ban
# A whole package is banned or later, never allowed.
#
# Only an allow stops the reach: an identifier that differs only by reaching
# allowed names needs no line of its own, so one allow on a root settles
# every identifier that differs only through it. A ban or a later says the
# difference is wrong, so it stops nothing: every identifier that reaches it
# takes its own line, banned or later too, or allowed with its own reason.
# internal/goos.GOOS is the one allow for the standard library branching on
# its own port. runtime's unexported names and methods are not followed at
# all, so runtime's exported identifiers are judged on their own
# declarations.
#
# filepath.IsAbs, exec.LookPath and os.Executable are allowed: each answers
# the same question the same way on every system. filepath.IsAbs reaches
# internal/filepathlite.IsAbs, whose line carries the same reason.
