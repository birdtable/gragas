docs/architecture.md: - **The release.** One recipe, from a clean annotated tag on main, that runs the full gate first on its exact tree, serving nothing from a stamp, and never pushes [supply.release.1, tests.selection.13]. The recipe's jobs carry a stated timeout, 20 minutes for the gate job, and a run that reaches it is cancelled [gates.command.8, tests.measures.3]. CGO off, `-trimpath`, a fixed build id, the same bytes from any directory [go.layout.4, supply.release.3]. Assets: one binary per OS and architecture with the embedded explorer and handbook, `SHA256SUMS`, an SBOM, provenance where the host offers it, the notices file [supply.release.9]. No signature: a release is pinned by its content hash, and `SHA256SUMS` lists each asset by digest. The explorer's marked copy is built by the explorer build target, which the recipe calls before the Go build, so it enters the two-build comparison. After the tag build and before publish, a step unpacks the archive, runs `version` and one start test, and compares digests [supply.release.6]. `--version` prints the tag, the commit and the toolchain [cli.exit.3]. The only workflow is the tag workflow: a gate job with a read-only token, then a publish job [supply.workflows.1, supply.workflows.3]. A dispatched run gates and never publishes.
