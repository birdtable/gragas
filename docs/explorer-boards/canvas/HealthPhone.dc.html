Health at 390 (phone)

Purpose

A rulebook owner or a consumer opens this view to judge how complete the rulebook is. It answers: how healthy is this rulebook, by the seven numbers the release publishes?

What it conveys, in order

  1. Each of the seven numbers, as a count over a total or a duration, in a code face so digits line up.
  2. How each is counted, in one line.
  3. What the release claimed beside what the engine computes, so a difference is seen.
  4. That no project is named in any number.

How the layout carries that order

One column of cards, the note on reading them last.

Standing on every row

Health numbers have no standing. Nothing here is conveyed by colour: each card is a name and a number in text.

Where it differs from the canvas, and why

  • The canvas had no health board: it is new. It is drawn from S29 and the list of seven numbers.
