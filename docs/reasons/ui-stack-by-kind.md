# The UI stack is declared by kind

A project declares the kind of UI it is built with, and only the stacks the foundation lists are used.

- **arch.structure.4** (Hard, active): A stack the foundation did not list is a stack nobody maintains; the declared kind is what lets the right pack be applied.

## Rules it serves

arch.decisions.1, arch.decisions.4, docs.links.2
