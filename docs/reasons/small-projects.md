# Small projects follow the same server-side and vocabulary rules

Small projects are held to the same rules as large ones where a gap would be a security or consistency fault. The rules below follow from that. Each states its own reason, with the strength and status it has in the rulebook.

- **docs.glossary.3** (Hard, active): Two programs that each spell out a code or status word drift apart, and a code that is also a sentence cannot be changed without breaking readers.
- **service.authz.4** (Hard, active): A control hidden in the page and not checked on the server is a suggestion; anyone can call the route directly.

arch.decisions.1, arch.decisions.4, docs.links.2
