# Why the pages rules are justified in one page

Three rules of the pages part carry their reason in this one page. Each rule keeps its status.

- **pages.cycle.2** (Lens, active): A page not in the ledger is a page nobody finds, and a ledger row with no page is a broken link on the index.
- **pages.cycle.4** (Lens, active): One repository had no file at all and 36 of 38 checked nothing at commit; a file that says what is not run is the difference between nothing to do and nothing done.
- **pages.cycle.5** (Lens, active): One set of design pages skipped both the pack and the index on a clean clone, so the published set was whatever the last machine had built.
