# Python rules that carry their reason in this page

Three rules of the Python part carry their reason in this one page. Each states the strength and status it has in the rulebook and the measurement or incident behind it.

- **py.cycle.3** (Lens, active): An install on every push is paid on every push, and an install that never checks the pin lets a stale venv pass for the pinned one.
- **py.cycle.5** (Lens, active): One project's desktop tool was red on import on the host that studied it, and a stamp that ignores the interpreter would have served the green of another host.
