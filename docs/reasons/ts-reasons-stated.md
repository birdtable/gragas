# Reasons for TypeScript rules that carry them on this page

These rules of the TypeScript part carry their reason in this one page. Each keeps its own status.

- **ts.cycle.3** (Lens, active): One package tracks 5,460 installed files.
- **ts.cycle.7** (Lens, active): Seven of the ten slowest tests in one main web application built a typed lint program inside the test body.
- **ts.cycle.8** (Lens, active): Service suites rebuilt their handler chain per test, and the tests were 126 of a 189 second push in one service.
- **ts.cycle.9** (Lens, active): Unit tests that reached for the network were among the slowest files in several services, and timed out at load.
